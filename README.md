# МедТезис

**МедТезис** — бесплатный русскоязычный учебный прототип сервиса для разбора медицинских утверждений из публикаций. Версия **0.4**.

## Как запустить

- Откройте `index.html` в браузере — установка не требуется.
- Для размещения в интернете можно включить бесплатный **GitHub Pages** для этого репозитория.

## Пользовательский сценарий

1. Вставьте русскоязычный текст или загрузите файл TXT.
2. Нажмите «Выделить утверждения»: программа предлагает несколько фрагментов, связанных с медициной.
3. Отредактируйте, отключите или добавьте тезисы, чтобы сохранить смысл оригинала.
4. Проверьте выбранные утверждения: известные сопоставляются с подготовленными разборами и ссылками на источники.
5. При необходимости выполните поиск публикаций в Europe PMC / PubMed, скачайте TXT-отчёт или пройдите мини-тест по медиаграмотности.

## Текущие возможности и ограничения

- Обработка исходного текста и эвристическое выделение тезисов выполняются локально в JavaScript в браузере.
- Подготовленная демонстрационная база содержит **7 разборов**. Незнакомые утверждения **не получают выдуманного вердикта**.
- Раздел поиска позволяет получать библиографические записи из Europe PMC и открывать PubMed, **но не анализирует автоматически новые исследования и не оценивает их качество**.
- Не все контекстные оговорки распознаются автоматически; перед проверкой тезисы можно уточнить вручную.
- При запросе к Europe PMC в сторонний сервис отправляются ключевые слова поиска; загруженный текст не пересылается на наш собственный сервер.
- Данные демонстрационных карточек и медицинские формулировки нуждаются в экспертной проверке и актуализации перед реальным использованием.
- Это **не медицинская консультация**, не средство диагностики и не инструмент для назначения лечения.

## Технологии

HTML, CSS, JavaScript. Не требуются платные API, база данных или сборка приложения.

## Развёртывание

В репозитории предусмотрен GitHub Actions workflow для размещения статического сайта в GitHub Pages. При необходимости в **Settings → Pages** выберите **GitHub Actions** в разделе Build and deployment → Source.

После успешного развёртывания адрес сайта будет:

https://economspmi.github.io/medtezis/

> Публикация исходного кода не означает, что страницы уже доступны по этому адресу: GitHub Pages необходимо включить и дождаться успешного выполнения workflow.
